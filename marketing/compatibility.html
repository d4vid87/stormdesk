Compatibility

Connect the station you already use.

Support depends on the station’s connection method and gateway—not only the brand on the outdoor sensor. Check the route below before installing.

Station or softwareHow it connectsWhat you need
WeatherFlow TempestWeatherFlow personal-use API and live station dataA Tempest account token and your station
EcowittCustom local upload to your StormDesk hostAn Ecowitt gateway or console that supports customized uploads
Ambient WeatherLocal compatible upload or Ambient Weather Network cloud pollingA compatible console/gateway, or AWN API credentials
Weather Underground uploadLocal WU-compatible upload endpointA console or weather program that can send WU-formatted updates
DavisLocal WeatherLink Live pollingA WeatherLink Live device reachable from the host
La CrosseCloud pollingLa Crosse account credentials; this unofficial connection may change
AcuRite and radio sensorsrtl_433 JSON forwarded to StormDeskA supported radio receiver and a computer running rtl_433
WeeWXWeather Underground-style uploaderA running WeeWX installation configured with the StormDesk host address

A brand may sell models with different gateways and upload features. The connection method above determines compatibility. Check your exact console or gateway documentation.

No station? No problem.

StormDesk can show worldwide forecast weather for a town, postcode, or saved place. Station-only history and measured observations become available after connecting a station archive.

Where the host fits

The desktop or headless StormDesk host receives and archives local readings, evaluates alert rules, and serves other household screens. Keep it running for closed-browser notifications and continuous local history.
