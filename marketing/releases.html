StormDesk 4.5.2

Published October 7, 2026 for Windows, macOS, Linux, Raspberry Pi, and Android.

Read full release notes

October 7 · broader hardware support

Samsung Smart Hub and Chromebook browsers now open the lighter StormDesk interface with weather, alerts, still radar, and basic History. AMD Linux AppImages use a safer rendering path, and new x86-64 and ARM64 browser-mode packages avoid GTK and WebKit.

September 27 · Linux split-screen fix

The AppImage now starts as a tileable window on Omarchy and Hyprland, so StormDesk can share the screen with another app. KWin keeps its first-frame maximization workaround. The dashboard and station data are unchanged.

September 23 app update

Weather, Radar, and History now use the simpler three-destination layout. Nine gauges stay fixed, History opens with snapshot cards, Radar focuses on the HookEcho map, and new installations start in OLED black with four other themes available in Settings.

September 26 browser update · Observatory

The browser app now uses a compact conditions card, up to ten forecast days, a central HookEcho radar panel, eight readings, and local signals with astronomy and device health. A local clock sits beside the official alert banner. Ten dark themes ship together, with Graphite Silver as the fresh-install default and existing choices preserved.

Browser updates

The 4.5.0 installers now include the Observatory dashboard, Settings home, Graphite Silver default, and current radar integration.

Checksums and signatures

The GitHub release includes SHA-256 checksums and signatures for supported desktop artifacts. Download files only from this website’s GitHub links or the official release page.
