Native Qt preview · 5.0.0-preview.3 · Free

Choose your StormDesk.

Get the updated Dashboard, movable gauges, animated weather and sunrise/sunset, and radar-colored NWS alerts on desktop and Android. Native apps include automatic release checks in Settings. This is the C++/Qt migration preview. Export a complete backup from 4.x before switching; existing installations do not automatically update to this preview.

Android · ARM64

Android app

Install the signed Instrument Pocket APK: four native gauges, animated current conditions and sun times, embedded HookEcho radar with automatic NEXRAD selection, and bottom navigation. Size and gauge order are in Settings. Tested on Galaxy S24 Ultra / Android 16; other devices remain preview.

Prefer the browser?

Open the current Instrument dashboard without installing anything. Choose a location or import your Tempest token to see compact gauges, sun times, NWS alert details and full-width HookEcho radar. The same browser keeps your theme and interface-size preferences. Desktop, mobile and browser share the updated Instrument design. The native packages above remain a migration preview pending device acceptance.

Open the browser app

The new app.mystormdesk.com address has separate browser storage from stormdesk.pages.dev. Existing users need to set up or pair the new address once. The old address remains available.

Release files and checksums

See the native 5.0 preview release for checksums, source revisions and migration notes. Windows and macOS builds are not vendor-signed or notarized. Keep your old app until your station is verified. Legacy 4.5.2 installers remain available for rollback.
